sysconfig steps for CCS v20.5.0.28__1.11.0

Follow these steps inside CCS Theia to configure peripherals that the project skeleton expects. After editing SysConfig, click "Generate" and then build the project.

1) Create a new CCS -> "CCS Project" -> choose target device MSPM0G3507. Use the provided empty_LP_MSPM0G3507_nortos_ticlang template if available.

2) Open the .syscfg file in the GUI.

3) GPIO:
   - Configure PB15 as a Digital Output (STEP)
   - Configure PB16 as a Digital Output (DIR)
   - Configure PB0 as a Digital Output (EN)

4) Timers:
   - Configure one timer (TIMA or TIMG) to be used as the STEP pulse timer. Add a callback interrupt for its compare match. Do NOT start it by default.
   - Configure another timer for the PID scheduler (periodic, e.g., 10 ms) and assign its ISR.

5) QEI / Encoder:
   - If SDK provides TIMG QEI, add QEI module with input pins PA15 (A) and PA16 (B). Enable counter and index if available (index not used).
   - If QEI not available, configure two GPIO interrupts on PA15/PA16 and implement quadrature decode in software.

6) UART (K230):
   - Add a UART instance (UART2 recommended) and assign TX/RX pins as in your board. Set Baud rate matching K230 (9600 or your protocol). Enable RX interrupt or ring buffer for reading commands.

7) Generate code.

8) Implement platform-specific mappings in board_init.c: inside Board_init() call the generated SysConfig init function (e.g. ti_msp_dl_configInit() or similar).

9) Replace stub functions in src/board_init.c and src/stepper.c (gpio_write, gpio_init_pin, uart_readline, uart_printf, timer start/stop) with the actual functions generated by SysConfig / TI driverlib.

10) Build and flash in CCS. Use the included README.md for recommended test commands.
